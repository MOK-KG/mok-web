# Платформа НОК Кыргызской Республики · веб

Внутренняя платформа для 14 сотрудников аппарата. Весь интерфейс за авторизацией.

## Стек

React 18, TypeScript, Vite, Tailwind, Radix UI, TanStack Query и Table,
react-hook-form, zod, i18next, date-fns, dnd-kit, Biome, Vitest. Менеджер пакетов — pnpm.

Тема — атрибут `data-theme` на `<html>`, не медиазапрос. Маршруты и провайдеры — `src/app/`.

Макеты: Figma, ссылки в `../docs/figma.md`.

## Чего не делать

- Не добавляй UI-библиотеки со своими стилями: MUI, Ant, Chakra, React Native Paper. Дизайн свой.
- Не предлагай SSR и Next.js. Публичных страниц нет.
- Не добавляй Redux, Zustand, MobX. Серверное состояние — TanStack Query,
  локальное — useState и useReducer.
- Не настраивай монорепо, workspaces, Turborepo, Nx. Приложения web и mobile независимы.

## Права доступа

- Проверяй права, а не роли: `useCan().can('tasks.create')`, `<Can permission>`, `RequirePermission`.
  Права приходят в сессии с бэкенда; список — `src/shared/config/permissions.ts`
- Раздел без права по прямой ссылке — экран 403 (`RequirePermission`), не пустой список и не редирект
- Смена роли — без перезапуска: сессия обновляется при фокусе, раз в минуту и после любого 403
- Не добавляй права на удаление журнала, сотрудников, задач, документов — их нет намеренно
- Матрица ролей в `permissions.ts` — заглушка для mock, настоящая на бэкенде (`../docs/roli.md`)

## Запросы, ошибки, сообщения

- Запросы — `api.get/post/put/patch/delete` из `src/shared/api/client.ts`, не голый `fetch`.
  Ошибка — `ApiError`: `status` (0 — нет сети или тайм-аут), `code` бэкенда, `fields`, `requestId`
- Что сказать пользователю, описывает мутация: `meta: { successMessage, errorMessage }`.
  Тосты показывает общий обработчик (`src/shared/api/feedback.ts`) — не вызывай `toast` в `onError`.
  Ошибка мутации — тост по умолчанию; `errorMessage: false` — экран показывает её сам.
  Ошибка загрузки — без тоста, экран показывает состояние сам
- Тексты ошибок — `errors.*`; новый код бэкенда — ключ `errors.code.<код>` и `knownErrorCodes`
- Тост вручную — `toast.success/error/info/warning` из `src/shared/lib/toast.ts`
- Подсказка — `Tooltip` из `src/shared/ui/Tooltip.tsx`; на мобильном — по долгому нажатию.
  Подсказка не заменяет `aria-label` / `accessibilityLabel` у кнопок-иконок

## Удаление

Почти ничего нельзя удалять:

- Запись журнала действий — никогда и никем
- Сотрудник — деактивируется, не удаляется
- Задача — закрывается или архивируется
- Документ — аннулируется, номер остаётся занятым

По сроку удаляются только резюме (6 месяцев), транскрипты и уведомления (12 месяцев).

## Согласованность чисел

Если на экране есть счётчик, он должен совпадать с содержимым.
«Готово 8» при трёх видимых карточках — ошибка. Пиши «3 из 8».
Это частая ошибка, проверяй каждый раз.

## Даты

Самая частая ошибка — даты. Только через `src/shared/lib/workDays.ts`, своих расчётов не пиши:

- Дата без времени — строка `YYYY-MM-DD` (`IsoDate`), не `Date`: иначе сдвиг на сутки по поясу
- «Сегодня» — `todayInBishkek()` (UTC+6), не `new Date()`
- Рабочие дни — `isWorkingDay`, `addWorkingDays`, `workingDaysBetween` по календарю КР
  (`src/shared/config/workCalendar.ts`, приказ Минтруда)
- Срок — `deadlineState()`: дедлайн только на рабочий день (`isValidDeadline`),
  «просрочено N дней» невозможно у даты в будущем
- Формат — `formatIsoDate()`, с днём недели; «N дней» — через формы числа i18next (`deadline.*`)
- Новый год календаря вносится по приказу Минтруда, тест сверяет норму рабочих дней по месяцам

## Стиль кода

- Отступ 2 пробела, одинарные кавычки, точка с запятой, строка до 100 символов (Biome)
- Компоненты в `src/features/`, переиспользуемое в `src/shared/ui/`
- Типы API генерируются из OpenAPI командой `pnpm api:sync`, руками не пишутся
- Токены из `src/shared/config/tokens.ts`, цвета в коде не хардкодятся
- Продублированы в web и mobile и должны совпадать побайтно — правь оба:
  `shared/config/{tokens,i18n,links,workCalendar,permissions}.ts`, `shared/lib/{workDays,date,text,toast}.ts`,
  `shared/api/{errors,request,feedback}.ts`,
  `features/tasks/{types,directory,absences,mock,deadline,filters,list,ui,mailQueue}.ts`,
  `features/notifications/api.ts`, `locales/*.json`.
  Тесты общих файлов живут в web
- Иконки: `shared/ui/icons.tsx` в web — источник; в mobile тот же набор путей (react-native-svg)
- Тексты интерфейса только через i18next, ключи во всех трёх файлах `src/locales/` (ru, ky, en)
